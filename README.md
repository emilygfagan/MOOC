# Sustainability Education Project: Lesson Plans for 1 ESO Students

## Overview
This repository contains a comprehensive teaching resource designed for 1 ESO students (ages 11–12) in Madrid public schools. The project focuses on sustainability and integrates real-world learning about Madrid's city systems, such as transportation, water, electricity, and internet. It is inspired by the Global Scholars curriculum and aligns with the theme of "Sustainable Cities."

## Objectives
The primary goal of this project is to educate students about sustainability through an engaging, interactive, and adaptable framework. By exploring local city systems, students develop critical thinking skills and learn to propose innovative solutions to urban challenges.

## Repository Contents
- **Lesson Plans**: Four detailed lesson plans covering sustainability topics.
  - Lesson 1: Introduction to Sustainability and Madrid's City Systems
  - Lesson 2: Exploring Transportation in Madrid
  - Lesson 3: Analyzing Energy Usage and Efficiency
  - Lesson 4: Designing Sustainable Solutions
- **Worksheets**: Printable resources for each lesson to support student engagement and understanding.
- **Rubric**: A comprehensive assessment rubric to evaluate student projects based on creativity, research, teamwork, and presentation.
- **Assessment Tools**: Guidelines for formative and summative assessments.

## How to Use
1. **Download Resources**: Clone this repository or download the ZIP file.
2. **Lesson Preparation**: Review the lesson plans and prepare materials as needed.
3. **Customization**: Modify worksheets and plans to suit your class's unique needs.
4. **Implementation**: Follow the lesson sequence to guide students through the project.
5. **Assessment**: Use the provided rubric to evaluate student outcomes.

## Why This Project Matters
This project equips students with the knowledge and skills to think critically about sustainability, fostering global awareness and responsible citizenship. It provides educators with adaptable tools to teach complex concepts effectively while connecting learning to students' local environment.
